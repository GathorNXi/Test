📊 Compteur de Partenaires Cookies

Ce bookmarklet vous permet de compter automatiquement le nombre de partenaires listés dans les bandeaux de consentement aux cookies.

📖 Instructions d'installation

  1. Faites glisser le bouton ci-dessous vers votre barre de favoris
  2. Ou faites un clic droit et sélectionnez "Ajouter aux favoris"
  3. Rendez-vous sur un site web avec un bandeau de cookies
  4. Cliquez sur le bookmarklet dans vos favoris

📌 Bookmarklet

Glissez ce lien dans votre barre de favoris :

🔍 Compter les Partenaires Cookies

✅ Ce que fait le bookmarklet

  • Détecte automatiquement la plateforme de consentement (Didomi, OneTrust, Quantcast/TCF)
  • Compte le nombre de partenaires publicitaires
  • Affiche le résultat dans une alerte
  • Enregistre aussi le résultat dans la console du navigateur

📝 Code source du bookmarklet

Pour les curieux, voici le code JavaScript non-minifié :

function countCookiePartners() {
    let results = [];

    // Détecter Didomi
    if (window.Didomi) {
        try {
            const vendors = window.Didomi.getUserConsentStatusForAll()?.vendors || {};
            const count = Object.keys(vendors).length;
            results.push(`📌 Didomi détecté: ${count} partenaires`);
        } catch(e) {
            results.push('Erreur Didomi: ' + e.message);
        }
    }

    // Détecter OneTrust
    if (window.OneTrust) {
        try {
            const vendors = window.OneTrust.GetDomainData()?.VendorsSummary || [];
            results.push(`📌 OneTrust détecté: ${vendors.length} partenaires`);
        } catch(e) {
            results.push('Erreur OneTrust: ' + e.message);
        }
    }

    // Détecter TCF (Quantcast, etc.)
    if (typeof __tcfapi === 'function') {
        __tcfapi('getVendorList', 2, (vendorList, success) => {
            if (success && vendorList) {
                const count = Object.keys(vendorList.vendors || {}).length;
                results.push(`📌 TCF (Quantcast) détecté: ${count} partenaires`);
                showResults();
            }
        });
    }

    // Recherche dans le texte de la page
    const textPatterns = [
        /(\d+)\s*partenaires?/i,
        /(\d+)\s*vendors?/i,
        /(\d+)\s*partners?/i
    ];

    const bodyText = document.body.innerText;
    textPatterns.forEach(pattern => {
        const match = bodyText.match(pattern);
        if (match) {
            results.push(`🔍 Trouvé dans le texte: ${match[1]} partenaires`);
        }
    });

    function showResults() {
        if (results.length === 0) {
            results.push('⚠️ Aucun bandeau de cookies détecté');
        }

        const message = `📊 Résultats pour ${window.location.hostname}:\n\n${results.join('\n')}`;
        alert(message);
        console.log(message);
    }

    setTimeout(showResults, 1000);
}

countCookiePartners();

❓ FAQ

Le bookmarklet ne fonctionne pas

Assurez-vous que :

  • Le bandeau de cookies est visible sur la page
  • Vous avez bien installé le bookmarklet dans vos favoris
  • Les pop-ups ne sont pas bloqués

Pourquoi certains sites affichent 0 partenaires ?

Certains sites n'utilisent pas de plateforme de consentement standard, ou chargent les informations de manière différente.

C'est sûr ?

Oui, le code est visible ci-dessus et ne fait qu'analyser la page actuelle. Aucune donnée n'est envoyée à l'extérieur.
